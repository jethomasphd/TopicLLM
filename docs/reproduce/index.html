Fork the repository or install the Python package. Your agent runs the documented workflow; you review the scientific decisions.

Start with the public Trump corpus.

The public archive and campaign-to-presidency configuration are included. Discover in 7,805 campaign posts, develop human-defined themes, then independently evaluate classification before estimating overall prevalence in 26,239 presidential posts. 1. Install and verify

Clone your fork, create and activate an isolated Python environment, then run:

python -m pip install ".[dev]"
topicllm --profile quickcheck --output-dir runs/check

The quickcheck verifies the bundled data and setup without model or API calls.

Or install the Python wheel.

2. Give your agent a concrete task

Read AGENTS.md, REPRODUCE.md and docs/protocol.json.
Verify the bundled Trump archive. Read examples/campaign-presidency-config.json.
Discover only in the campaign; reserve the presidency for validated measurement.
Explain the topics and model coverage. Prepare the evidence for researcher review.
Prepare the next steps and their API costs for me to review.
Do not invent human labels, approvals or historical outputs.

The agent handles execution and records the evidence. You review the meaning, the validation and the scientific interpretation.

3. Run discovery

python -m pip install ".[ml,dev]"
topicllm --profile trump-demo --output-dir runs/trump --plan
topicllm --profile trump-demo --output-dir runs/trump

This runs the documented Trump discovery profile locally. The first run may download model and NLP resources; discovery makes no paid OpenAI calls.

4. Continue the research workflow

Set your OpenAI key privately and declare an API budget. Your agent prepares naming evidence and a review packet. Two researchers define the themes and codebook. Development annotations select a classifier; a separate untouched sample evaluates that frozen choice. Researchers inspect and accept its errors before it labels the presidential corpus.

Use the full execution guide for exact commands, stage artifacts and approval records. Read the methods for the scientific decisions.

Keep inputs, settings, responses and review records with each run. Topic models and LLMs can produce different results across runs; the evidence trail makes those results inspectable.
