# TopicLLM Language lens identity

The author selected **02 — Language lens** from four image-generated workshop directions: Semantic clusters, Language lens, Model brackets and Topic monogram.

The production `topicllm-mark.svg` is a manually constructed, editable vector interpretation of that selected direction. Six flat geometric segments frame three descending text lines. The text is the subject; the surrounding lens represents inspecting language and making its structure legible. Segment and line counts are graphic choices, not measured research results.

The mark uses navy `#153b63`, blue `#2a67ba`, teal `#398d90` and an ivory `#f7f6f1` ground. The integral ground preserves the text and aperture separation on light and dark surfaces. There are no raster textures or filters. The site wordmark remains IBM Plex Sans. Navigation, favicon and repository README reference the same SVG.

The geometric document-card hero from the second iteration is retained. See `ARTWORK-V2.md` for its generation prompt and conceptual-artwork provenance.
